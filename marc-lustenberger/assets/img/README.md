# Bilder

Die Seite erwartet folgende Dateien (JPG, lange Kante ca. 2000 px). Quelle: Bildmaterial von
marc-lustenberger.ch bzw. die Rechte der jeweiligen Fotograf:innen.

Alle Fotos werden per CSS einheitlich interpretiert (Schwarz-Weiss, harter Kontrast, Körnung) –
sie müssen also nicht vorbearbeitet werden. Fehlt eine Datei, zeigt der Rahmen eine
Sägemehl-Textur mit einer Beschreibung, welches Motiv hierher gehört.

| Datei                | Motiv                                                        | Format  |
|----------------------|--------------------------------------------------------------|---------|
| `hero.jpg`           | Portrait im Sägemehl, direkter Blick, eng geschnitten         | 4:5     |
| `ring.jpg`           | Wettkampf: Griff, Anspannung, Sekunde vor dem Schwung         | 4:5     |
| `portrait.jpg`       | Ruhiges, lachendes Portrait nach dem Fest                     | 4:5     |
| `saegemehl.jpg`      | Detail: Hände, Sägemehl, Zwilchhose                           | 21:9    |
| `sachseln-2025.jpg`  | Sachseln 2025: Schlussgang oder Siegerfoto mit Muni «Fredy»   | 16:9    |
